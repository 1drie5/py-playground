# LLM Semantic Book Recommender

A semantic book recommendation system that uses LLMs and vector search to find books based on natural language queries.

**Key Features:**
- Semantic search using vector embeddings
- Sentiment analysis of book descriptions
- Text classification with LLMs
- Interactive Gradio dashboard

**Project Components:**
1. `data-exploration.ipynb` - Data cleaning and exploratory analysis of the book dataset
2. `text-classification.ipynb` - Categorizing books using LLM-based text classification
3. `sentiment-analysis.ipynb` - Extracting emotional tones from book descriptions
4. `vector-search.ipynb` - Building semantic search with vector embeddings and ChromaDB
5. `gradio-dashboard.py` - Interactive web interface to search and explore book recommendations
